AnalyticComb.CYC — Method
CYC(z,max)
CYC(z,u,max)

Cycle operator (Pólya logarithm).

Defined as $A = CYC(B) \implies A(z) = \sum_{1}^{\infty} \frac{\phi(k)}{k} log \frac{1}{1-z^k}$, or with marker $u$ for number of components: $A(z, u) = \sum_{1}^{\infty} \frac{\phi(k)}{k} log \frac{1}{1 - u^k z^k}$. Returns a SymPy :Sym object.

AnalyticComb.MSET — Method
MSET(z,max)
MSET(z,u,max)

Multiset operator (Pólya exponential operator).

Defined as $A = MSET(B) \implies A(z) = exp(\sum_{1}^{\infty} \frac{1}{k} B(z^k))$, or with marker $u$ for number of components: $A(z, u) = exp(\sum_{1}^{\infty} \frac{u^k}{k} B(z^k))$. Returns a SymPy :Sym object.

source
AnalyticComb.PSET — Method
PSET(z,max)
PSET(z,u,max)

Powerset operator (modified Pólya exponential operator).

Defined as $A = PSET(B) \implies A(z) = exp(\sum_{1}^{\infty} \frac{(-1)^{k-1}}{k} B(z^k))$, or with marker $u$ for number of components: $A(z, u) = exp(\sum_{1}^{\infty} \frac{(-1)^{k-1} u^k}{k} B(z^k))$. Returns a SymPy :Sym object.

source
AnalyticComb.SEQ — Method
SEQ(z)
SEQ(z, u)

Sequence operator (Pólya quasi-inverse operator).

Defined as $A = SEQ(B) \implies A(z) = \frac{1}{1 - B(z)}$, or with marker $u$ for number of components: $A = SEQ(uB) \implies A(z, u) = \frac{1}{1 - u B(z)}$ (Flajolet & Sedgewick, Fig. III.7, p. 170).

AnalyticComb.bgf_moments — Method
bgf_moments(bgf::Function, n::Integer)
bgf_moments(bgf::SymPy.Sym, n::Integer; z=SymPy.symbols("z"), u=SymPy.symbols("u"))

Compute exact analytical moments (mean, var, std, and total weight/count count) at size n from a Bivariate Generating Function (BGF) $A(z, u)$ where $z$ marks size and $u$ marks a combinatorial parameter $\chi$.

Uses Proposition III.2 of Flajolet & Sedgewick (Analytic Combinatorics, p. 158):

  • $\mathbb{E}_n(\chi) = \frac{[z^n] \partial_u A(z, u)|_{u=1}}{[z^n] A(z, 1)}$
  • $\mathbb{E}_n(\chi(\chi - 1)) = \frac{[z^n] \partial_u^2 A(z, u)|_{u=1}}{[z^n] A(z, 1)}$
  • $\mathbb{V}_n(\chi) = \mathbb{E}_n(\chi(\chi - 1)) + \mathbb{E}_n(\chi) - \mathbb{E}_n(\chi)^2$

Returns a NamedTuple: (mean = ..., var = ..., std = ..., count = ...).

AnalyticComb.markov_dominant_pole — Method
markov_dominant_pole(p00::Real, p01::Real, p10::Real, p11::Real, l::Integer)

Compute the dominant real singularity $z_0$ of the 1st-order Markov run-avoidance generating function (cleared denominator $(1 - p_{00} z) - p_{01} p_{10} z \sum_{k=1}^{l-1} p_{11}^{k-1} z^k = 0$), together with the coherent persistence pole $z_{\text{persist}} = 1 / p_{11}$ of $(1 - p_{11} z)^{-1}$.

As coherent persistence $p_{11} \to 1$, the run-avoidance decay rate $1/z_0$ drops and $z_{\text{persist}} - 1 \to 0^+$.

Returns (z0 = ..., gap = z0 - 1.0, growth_rate = 1 / z0, persistence_pole = 1 / p11, persistence_gap = 1 / p11 - 1.0).

source
AnalyticComb.runs_dominant_pole — Method
runs_dominant_pole(p::Real, q::Real, l::Integer)

Compute the dominant real singularity $z_0$ of the run-avoidance generating function (irredundant denominator $1 - q z \sum_{j=0}^{l-1} (p z)^j = 0$), where $p + q = 1$ and $l \ge 1$.

For run-avoidance, $P(\text{no } l\text{-run in } n) \sim c \cdot z_0^{-n}$: as $p$ increases, $z_0 > 1$ grows and the avoidance survival rate $1/z_0$ drops. Conversely, the coherent persistence pole $z_{\text{persist}} = 1/p$ of $(1 - pz)^{-1}$ satisfies $z_{\text{persist}} - 1 \to 0^+$ as $p \to 1$ (Flajolet & Sedgewick, Section V.2–V.3).

Returns (z0 = ..., gap = z0 - 1.0, growth_rate = 1 / z0, persistence_pole = 1 / p, persistence_gap = 1 / p - 1.0).

markov_bin_runs_bgf(p00, p01, p10, p11, l, z, u; mode="count_ge", init_probs=nothing)

AnalyticComb.weighted_bin_runs_bgf — Method
weighted_bin_runs_bgf(p, q, l, z, u; mode="count_ge")

Weighted Bivariate Generating Function (BGF) $W(z, u)$ for consecutive runs in binary words of Bernoulli trials with probabilities $p$ and $q$, where $z$ marks sequence length $n$ and $u$ marks a run parameter (Flajolet & Sedgewick, Sections I.4 & III.3):

  • mode="count_ge" (default): $u$ marks the number of maximal runs of length $\ge l$: $W(z, u) = \frac{1 + (u - 1) p^l z^l}{1 - (p + q)z - (u - 1) q p^l z^{l+1}}$
  • mode="length_ge": $u$ marks the total number of elements belonging to maximal runs of length $\ge l$ (the numerator of RQA Determinism / Laminarity): $W(z, u) = \frac{1 + \beta(z, u)}{1 - qz(1 + \beta(z, u))}$, where $\beta(z, u) = \frac{pz - p^l z^l}{1 - pz} + \frac{(upz)^l}{1 - upz}$
  • mode="count_eq": $u$ marks the number of maximal runs of exact length $l$: $W(z, u) = \frac{1 + (u - 1) p^l z^l (1 - pz)}{1 - (p + q)z - (u - 1) q p^l z^{l+1} (1 - pz)}$
  • mode="double_count_ge": $u$ marks the number of maximal runs of either outcome ($p$ or $q$) of length $\ge l$.
source

AnalyticComb.random_mapping_moments — Method
random_mapping_moments(n::Integer)

Exact finite-$n$ and asymptotic statistics for a uniformly random discrete dynamical mapping $f: \{1, \dots, n\} \to \{1, \dots, n\}$ (Flajolet & Sedgewick, Section II.5.2 & Section VII.3.3):

Returns a NamedTuple:

  • expected_cyclic_nodes: exact $\mathbb{E}_n[\text{periodic states}] = Q(n) = \sum_{k=1}^n \frac{n!}{(n-k)! n^k} \sim \sqrt{\pi n / 2}$
  • expected_components: exact $\mathbb{E}_n[\text{attractors}] = \sum_{k=1}^n \frac{1}{k} \frac{n!}{(n-k)! n^k} \sim \frac{1}{2}(\log(2n) + \gamma)$
  • prob_connected: exact probability of a single connected attractor $Q(n) / n \sim \sqrt{\pi / (2n)}$
  • expected_leaves: exact expected number of transient terminal states (in-degree 0) $n (1 - 1/n)^n \sim n / e$
  • expected_fixed_points: exact $1.0$
  • cyclic_nodes_asym: $\sqrt{\pi n / 2}$
  • components_asym: $0.5 (\log(2n) + \gamma)$
  • tail_len_asym: $\sqrt{\pi n / 8}$ (mean transient distance $\lambda$ to limit cycle)
  • cycle_len_asym: $\sqrt{\pi n / 8}$ (mean limit cycle length $\mu$ from random state)
  • rho_len_asym: $\sqrt{\pi n / 2}$ (mean total orbit length $\rho = \lambda + \mu$)
  • largest_component_asym: $0.7582 n$
  • largest_tree_asym: $0.48 n$

transfer_matrix_moments(T::AbstractMatrix{<:Real}, mark_matrix::AbstractMatrix{<:Real}, n::Integer;
                        init_dist=nothing, final_vec=nothing)

Compute exact analytical moments (mean, var, std, count) for the cumulative marked transition statistic $\chi = \sum_{t=1}^n M_{s_{t-1}, s_t}$ over paths of n transitions on an $m \times m$ transfer/transition matrix T (Flajolet & Sedgewick, Theorem V.7 & Section V.6):

$G(z, u) = \mathbf{p}_0^T \bigl(\mathbf{I} - z \mathbf{T}(u)\bigr)^{-1} \mathbf{f}, \qquad T_{ij}(u) = T_{ij} \, u^{M_{ij}}.$

Uses exact degree-2 Taylor1 propagation in $u = 1 + du$ in $O(\min(n m^2, m^3 \log n))$ time. If init_dist is nothing, defaults to the stationary distribution when T is row-stochastic, and ones(m) otherwise. final_vec defaults to ones(m).
